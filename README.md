## Objetivo de este repositorio
Preparar el repositorio Git, organizar los archivos iniciales, establecer convenciones de código y documentar cómo ejecutar y colaborar en el proyecto.

## Ambiente de desarrollo
- Visual Studio Code
- Navegador actualizado (Chrome, Edge o Firefox)
- Git y cuenta de GitHub
- HTML, CSS y JavaScript para el prototipo web inicial

Para iniciar, abre la carpeta en VS Code y ejecuta `index.html` en el navegador. También puedes usar la extensión Live Server.

## Estructura
- `index.html`: página principal.
- `css/`: hojas de estilo.
- `js/`: comportamiento de la interfaz.
- `docs/`: documentación y registro del Sprint 1.

## Flujo de trabajo
- `main`: versión estable.
- `develop`: integración del equipo.
- `feature/nombre-tarea`: nuevas funcionalidades.
- `fix/nombre-error`: correcciones.
